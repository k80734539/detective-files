# 事務所結尾：三案全破之後（草稿）

> 目的：把《老街迷香》《霧鎖山莊》《夜市無聲》收成同一個系列，並給「第四案」一個真正的開頭。
> 觸發條件：事務所頁面三案「已偵破」且三張雲朵線索（名片、土地讓渡書、採購名單）都點亮。
> 形式：事務所頁出現「📜 深夜的事務所」按鈕，點開是一段短對話（約 25 句），只播一次，之後可重看。
> 這份只是文字草稿，**沒有放進遊戲**。有三處標了【選擇】，請你決定。

## 場景：深夜的事務所

背景：事務所桌面，三份文件並排，窗外下著小雨。

```
N  三份文件，攤在桌上。
N  一張名片。一份土地讓渡書。一份採購名單。
N  每一份的角落，都印著同一朵雲。
許晴  老街、山莊、夜市……三個地方，三個人，同一朵雲。
N  我把它們排成一列，才發現一件事。
許晴  三份文件，措辭一模一樣。「為了您好」「為了大家好」「為了這裡好」。
許晴  不是巧合。是同一套說法，一個人教出來的。
N  門口，傳來兩下很輕的敲門聲。
```

（周予安進來，肩膀淋濕了，手上抱著筆記本。）

```
周予安  ……打擾。我路過。
許晴  你的外套都濕了，不像路過。
周予安  （把筆記本放在桌上）我把三件案子的時間，排了一遍。
周予安  山莊，二十年前，處理完畢。夜市，十年前，簽了三十一份。老街，更早。
周予安  不是各自為政。是有人，一個地方、一個地方，慢慢往外擴。
許晴  你為什麼這麼在意雲嶺？
```

（他沉默了一下，把筆記本翻到最後一頁。）

```
周予安  ……我媽的店，也有一朵雲。
周予安  我那時候十五歲，不懂為什麼她簽了字，隔天，就把鑰匙放在桌上。
周予安  記錄只能寫發生了什麼。寫不了，她那天晚上，是什麼表情。
N  我想起阿嬤，也是這樣。
許晴  ……我阿嬤，也是。
N  我們誰都沒再說話。雨聲，變得很清楚。
```

## 結尾：第四份卷宗

```
N  我從口袋裡，拿出那張匿名的紙條。
許晴  這張紙條，從夜市起，就一直跟著我。你看一下這個字。
周予安  （仔細看了很久）字跡不是社長的。我對過。
周予安  但是，這個字，我在別的地方，見過。
許晴  哪裡？
```

【選擇】這裡的伏筆，你想怎麼收？

| 選項 | 內容 | 效果 |
|---|---|---|
| A　內部有人 | 他說：「在雲嶺的內部公文上。」→ 暗示有人在公司裡想讓真相出來 | 偏懸疑，下一案可以接「吹哨者」 |
| B　與許晴有關 | 他說：「在妳阿嬤留下的帳本裡。」→ 把許晴的過去拉進主線 | 偏情感，最有衝擊，但需要你設定阿嬤的故事 |
| C　先留白 | 他說：「……我想起來再告訴妳。」 | 最安全，不鎖死設定 |

```
N  卷宗櫃最上面那一格，不知什麼時候，多了一個空白的資料夾。
N  上面，沒有標題。
```
